# Embedded terminal fonts

JetBrains Mono **NL Nerd Font Mono**, regular and bold, from Nerd Fonts **v3.5.1**.
The Mono variant keeps patched icon glyphs inside a terminal cell; NL disables programming ligatures.

Source: https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/JetBrainsMono/NoLigatures

- `LICENSE.txt`: JetBrains Mono SIL Open Font License 1.1.
- `AUTHORS.txt`: upstream font authors.
- `NERD-FONTS-LICENSE.txt`: Nerd Fonts and bundled icon license notices.

The fonts are embedded in the executable. Users do not have to install them in the OS.
